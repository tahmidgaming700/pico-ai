## Reporting a Vulnerability

Security and privacy are fundamental to Pico AI. If you discover a security vulnerability or privacy flaw (such as unexpected network exfiltration or memory leakage), please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Email the maintainer directly at: `tahmidgaming700@gmail.com` with the subject line `[SECURITY] Pico AI Vulnerability Report`.
3. Include steps to reproduce the issue and any relevant logs or diagnostic reports.

We aim to acknowledge reports within 48 hours and provide a fix or mitigation promptly.
